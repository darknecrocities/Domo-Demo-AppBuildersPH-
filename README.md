# 🐼 DomoDomo — React Keynote Presentation Framework
### AppBuildersPH Presentation · Minimalist Monochrome Edition

An open-source, minimalist monochrome presentation web framework built with **React 19**, **Vite**, and **TypeScript**, documenting the origin, engineering journey, community impact, and agentic future of [DomoDomo](https://domodomo.site/).

Created by **Arron Parejas** (Founder of DomoDomo, Machine Learning Engineer Intern, and Former GDGoC – Holy Angel University Chapter Lead).

---

## 📖 Presentation Narrative (15 Slides)

1. **Slide 01 — Title & Manifesto**: *DomoDomo: The Open-Source Local-First AI & Productivity Platform*
2. **Slide 02 — The Creator**: Introducing Arron Parejas (ML Engineer, GDGoC-HAU Chapter Lead, Hackathon Champion) with ecosystem affiliations.
3. **Slide 03 — The Student Struggle**: The exhaustion of switching 10–15 tabs per task. *"What if everything people need could exist in one place?"*
4. **Slide 04 — The Reunion & Caffeine.ai Hackathon**: Reconnecting with teammate Ram after 5 years post-pandemic. Sleepless nights, pure grit, and winning 1st Place Championship.
5. **Slide 05 — The Story of the Cap**: How a freebie hackathon cap became DomoDomo's permanent mascot symbol for humility, curiosity, and roots.
6. **Slide 06 — Community as Catalyst**: Leading GDGoC Holy Angel University. Mentoring developers, democratizing knowledge, and creating opportunities.
7. **Slide 07 — Evolution Phase 1 (Web Utilities to Client Sandbox)**: Replacing servers with WebAssembly (FFmpeg.wasm, pdf-lib, Tesseract.js). 100% offline, zero data leaks.
8. **Slide 08 — Evolution Phase 2 (The Leap to Local Agentic AI)**: Direct integration with local Ollama (`localhost:11434`) and browser neural nets (`@xenova/transformers`).
9. **Slide 09 — The 240+ Tools Ecosystem**: 17 specialized suites (PDF, Photo, Security, Forensics, Developer, ML, Spatial 3D, Converters).
10. **Slide 10 — Domo Agent Hub**: Multi-agent pipelines (Sequential & Parallel persona chains), MCP local filesystem bridge, and local cognitive journaling (`domo_journal.md`).
11. **Slide 11 — DomoSkills: The Agent Marketplace**: 200+ skills for Google Antigravity, Claude Code, Cursor, and Codex. One-line CLI installation.
12. **Slide 12 — Advanced AI Studio**: Node-based visual flow builder, 6 local fine-tuning methods (QLoRA, LoRA, DPO), and local vector RAG.
13. **Slide 13 — Significance to Students & Developers**: Zero paywalls, zero cloud telemetry, air-gapped readiness, empowering builders anywhere.
14. **Slide 14 — Core Philosophy**: *"Done is better than perfect. Shipped is better than planned."*
15. **Slide 15 — The Road Ahead & Connect**: Future milestones, connection links, and scan-to-connect QR code.

## ⌨️ Keyboard Shortcuts

| Key | Action |
| :--- | :--- |
| `→` / `Space` / `PageDown` | Next Slide |
| `←` / `PageUp` | Previous Slide |
| `Esc` or `G` | Toggle Slide Overview Grid Drawer |
| `N` | Toggle Speaker Notes Panel |
| `F` | Toggle Fullscreen Mode |
| `T` | Toggle Monochrome Dark / Light Theme |
| `?` | Toggle Keyboard Shortcuts Legend |
| `Home` / `End` | Jump to First / Last Slide |

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/darknecrocities/Domo-Demo-AppBuildersPH-.git
cd Domo-Demo-AppBuildersPH-

# Install dependencies
npm install

# Start the development server
npm run dev

# Build for production
npm run build
```
